<objective>
Make the gateway safe by default on a developer machine (GW-01): loopback-only bind, WebSocket Origin allowlist, frame size cap, application-level `pong`, and liveness termination of dead sockets, with tests for hostile transport-level input.

Purpose: today `server.listen(port)` binds every interface and any web page open in the user's browser can connect to `ws://localhost:8088/ws` and drive tmux/ssh shells (cross-site WebSocket hijacking). Concerns file: "Unauthenticated WebSocket that spawns shells/SSH". Phase 8 later adds token auth and allows a non-loopback bind; until then a non-loopback bind is refused outright.
Output: config helpers, hardened bootstrap, tests, server README.

Scope guard: this plan adds no network exposure and no authentication. Message-level schema validation of client frames is Phase 6 (it needs the shared protocol package from Phase 2); here only structural checks that need no schema are done. The port stays 8088 (contract spec section 1; ADR-006).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network -> listener | Who can reach the port (now loopback only) |
| browser page -> WebSocket upgrade | Any site the user visits can try to open ws://localhost:8088/ws |
| client frame -> gateway | Untrusted JSON of any shape and size |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-04-01 | Elevation of Privilege | listener bound on all interfaces | critical | mitigate | Default bind 127.0.0.1; assertLoopbackBind refuses any other HOST until token auth exists (Phase 8) |
| T-04-02 | Spoofing | cross-site WebSocket hijacking and DNS rebinding | high | mitigate | verifyClient Origin allowlist; a rebinding page still carries its own attacker Origin and is refused with 403 |
| T-04-03 | Denial of Service | oversized frames | medium | mitigate | maxPayload 1 MiB closes with 1009 |
| T-04-04 | Denial of Service | dead or half-open sockets accumulate | medium | mitigate | Protocol ping/pong liveness terminates unresponsive sockets; interval unref'd and cleared on close |
| T-04-05 | Tampering | non-object or malformed frames | medium | mitigate | Structural guard before dispatch; unknown types ignored; schema validation arrives with Phase 6 |
| T-04-06 | Information Disclosure | /health unauthenticated | low | accept | Returns only status, agent count and a timestamp, and is now reachable from loopback only |
| T-04-07 | Elevation of Privilege | Origin header absent (non-browser clients) | low | accept | Only local processes can connect; they can already run the same shells directly |
| T-04-SC | Tampering | npm/pip/cargo installs | high | accept | No packages installed in this plan |
</threat_model>
