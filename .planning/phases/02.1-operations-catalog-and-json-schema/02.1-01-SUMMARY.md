## Deviations from Plan

**1. [Rule 1 - Spec precision] `update-empty-name` added to the allowlist.** The plan said "plus any other entry running the test shows"; whitespace-only name passes `minLength` because `trim` is only `x-trim`. Reason recorded in the test.

**2. [Rule 3 - Blocking] `assertSupported` walker added to the evaluator.** The evaluator only checks keywords on schemas it visits, so a generator keyword on an unvisited branch would slip through; the walker checks the whole document.

**3. Fixture-name collision.** `error-unknown-code` exists in both `invalid.json` and `http.json` malformed; the planned uniqueness check was replaced by an unambiguity check on allowlisted names only.

**4. Environment.** The worktree had no `node_modules`; symlinked the main checkout's root and `server/` `node_modules` (git-ignored, not committed) to run the gates.

STATE.md, ROADMAP.md and REQUIREMENTS.md were not updated in this worktree (parallel wave; the orchestrator owns them after merge).
