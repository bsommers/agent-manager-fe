<objective>
Grow the shared protocol package from the eight existing messages toward the full v2 contract of docs/superpowers/specs/2026-11-07-fe-be-contract.md (INT-08). This plan lays the foundation and the client half: it extracts the field-spec engine into its own module, ships the `hello`/`hello_ack` handshake end to end as the tracer, adds the error vocabulary, and adds every client-to-gateway message (`ping`, `agent:update`, `agent:history`, `agent:approve`, `reqId` and `agent:create` extensions) with golden fixtures. Plan 02-03 adds the gateway-to-client half, HTTP shapes and limits; plan 02-04 adds the surface snapshot, `contract:check` and CI.

Purpose: later phases implement against an executable schema instead of prose; the fixtures are language-neutral inputs for the mock server (Phase 7) and the cvm/climah adapters (Phases 24-25).
Output: `fieldspec.ts`, `capabilities.ts`, `errors.ts`, extended tables, fixtures, conformance tests. Zero change to FE or server runtime code.

Re-cut note: this plan was narrowed from the original 02-02 (which also held the server messages, HTTP shapes and limits) because that scope exceeded one executor context; the dropped parts live in 02-03. The spec is the normative source for field names, optionality and phase tags; this plan states only the validator-level rules the spec does not spell out.
</objective>
