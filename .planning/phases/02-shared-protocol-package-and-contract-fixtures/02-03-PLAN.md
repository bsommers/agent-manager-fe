<objective>
Make contract drift impossible to merge silently: derive a canonical surface description from the package, pin it in a committed snapshot, classify differences as breaking or additive, expose that as `npm run contract:check`, and run it with the rest of the suite in CI (INT-08 acceptance: "CI fails on an incompatible schema change").

Purpose: the FE and gateway evolve in separate phases and eventually separate repos; this gate is what keeps them interoperable.
Output: surface module, snapshot, check CLI, root scripts, CI workflow, package README.

Safety: the CLI runs git through an argv array only (never a shell string) and only reads from git. The CI workflow has read-only permissions and no secrets.
</objective>

<task type="auto" tdd="true">
  <name>Task 2: Classify differences and ship the contract:check gate</name>
  <files>packages/protocol/src/surface.ts, packages/protocol/src/index.ts, packages/protocol/src/__tests__/surface.test.ts, packages/protocol/scripts/contract-check.ts, package.json</files>

  <behavior>
    - diffSurface(prev, next) returns breaking and additive lists of human-readable strings
    - breaking: a message type removed; a field removed; a field kind changed; an optional field made required; a new required field on an existing type; an enum value removed; an error code or capability removed; a limit lowered; the contract number lowered
    - additive: a new message type (even with required fields); a new optional field; a new enum value; a new error code or capability; a limit raised
    - evaluate(prev, next) returns pass with notices when there are no breaking changes, pass with a notice when breaking changes exist and next.contract is greater than prev.contract, and fail otherwise
  </behavior>
  <action>
Write the diff and evaluate tests first (one test per bullet above, using small hand-built surfaces), then implement diffSurface and evaluate as pure functions in surface.ts and export them. Implement scripts/contract-check.ts as a vite-node script: parse a --base argument (default HEAD); resolve the base snapshot by running git show with arguments ref plus a colon-joined path via the child_process execFileSync argv form; if the ref or file does not exist print that the base has no snapshot and exit 0 only when the file is absent at an existing ref (a new package), and exit 2 with a clear message when the ref itself cannot be resolved; compare the committed snapshot with the live describeSurface() and exit 1 with the instruction to run npm run contract:update when they differ; then run evaluate against the base and exit 1 listing the breaking changes when it fails. Add root package.json scripts contract:check (vite-node packages/protocol/scripts/contract-check.ts) and contract:update (vitest run packages/protocol/src/__tests__/surface.test.ts -u). Never pass user text to a shell.
  </action>
