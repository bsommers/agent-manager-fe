<objective>
Make contract drift impossible to merge silently: derive a canonical surface description from the package, pin it in a committed snapshot, classify differences as breaking or additive, expose that as `npm run contract:check`, and run it with the rest of the suite in CI (INT-08 acceptance: "CI fails on an incompatible schema change").

Purpose: the FE and gateway evolve in separate phases and eventually separate repos; this gate is what keeps them interoperable.
Output: surface module, snapshot, check CLI, root scripts, CI workflow, package README.

Depends on 02-02 and 02-03 (the executable tables, errors, capabilities, HTTP shapes and limits it describes). This plan was renumbered from the original 02-03 when the table work was split out.

Safety: the CLI runs git through an argv array only (never a shell string), only reads from git, and validates the ref before use. The CI workflow has read-only permissions and no secrets.
</objective>
